# QQ 小程序壳（web-view 方案）

本目录是暗棋象棋的 **QQ 小程序外壳**，游戏本体是 `D:\xiangqi` 下那套 H5 网页，
通过 `<web-view>` 组件整体嵌入，因此**游戏代码无需重写**。

## 上线前必改的两处
1. `project.config.json` 里的 `appid` → 换成你在 QQ 小程序后台申请的真实 AppID。
2. `pages/index/index.js` 里的 `url` → 换成你备案好、已加白名单的真实 https 域名地址。

## 使用步骤
1. 下载安装「QQ 小程序开发者工具」。
2. 用开发者工具「导入项目」，目录选本 `qq-miniprogram` 文件夹。
3. 填好 AppID 与域名后，点「预览」用手机 QQ 扫码自测。
4. 自测 OK → 后台提交审核 → 审核通过发布。

## 注意
- web-view 加载的网页域名，必须在 QQ 小程序后台「开发 → 开发设置 → 业务域名」
  里添加，并下载校验文件放到该域名网站根目录（详见《部署指南.md》）。
- 网页本身必须用 HTTPS，且域名已完成 ICP 备案（见《部署指南.md》）。

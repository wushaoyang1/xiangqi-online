玩法规则

  • 双方在传统象棋外各多一枚暗棋，只有你自己能看到。
  • 每回合先走 1 步普通棋子；若该暗棋已就绪，棋盘会自动高亮暗棋可走格，点高亮格即可走暗棋（也可点棋盘右侧的「结束回合」跳过）。
  • 暗棋机会不叠加（最多待行动 1 次）。走暗棋不单独占回合；行动后重新累计：再走 2 步普通棋子才可再次行动。
  • 暗棋每次走 1 格，可走直线也可走斜线；能与普通棋子重叠（不阻挡）。
  • 主动出击 · 吃掉敌子：暗棋可主动移动到敌方棋子所在格，直接吃掉对方并存活（落点显示红色攻击环）。
  • 阻挡 + 同归于尽：任何棋子（含车、炮等直线棋子）前进路径上若意外触碰敌方暗棋，即触发同归于尽并播放爆炸动画 + 提示，不只限于落在暗棋上。
  • 即便暗棋与友方棋子重叠，敌方吃掉该友方棋子时，仍会触发同归于尽。
  • 被将军也可自由走子：本作不强制"应将"——被将军时仍可走任意棋子，再用暗棋（后置阶段）去吃掉将军的子来解围；只有被完全堵死、无任何子可动才算无着可走。
  • 单人也能玩：选「单人对 AI」即可人机对战（AI 执黑或执红、可选难度）。人机模式不会弹出交接遮罩，你的暗棋只有你能看见。
  • 联网对战（不限 WiFi）：选「联机对战」后，点「随机匹配」系统自动分配在线对手，或点「创建房间」生成邀请链接发给好友。服务器部署在公网，双方无需同一 WiFi 也能对战。联机时暗棋位置只存在于你自己的电脑上，从不上传服务器，对方就算翻代码也看不到；对手棋子撞上你暗棋的判定，由你这台电脑裁决后再同步给对方。
  • 观战 / 回放 / 战绩：填房间号点「观战」即可旁观他人对局（暗棋位置对观战者始终隐藏）；每局结束自动保存回放到本机，点「我的回放」可随时回顾（也能导入别人分享的回放文件）。回放里勾选「显示暗棋」即可看到本机已知的暗棋位置（联机时仅你自己的暗棋；本地双人 / AI 两边都在本机则都显示）；你的胜负战绩自动记录在本机。
  • 悔棋 / 认输 / 聊天 / 段位：联机对局中可点「悔棋」向对手发起悔棋（需对方同意，暗棋坐标一并还原，保密不破）；点「认输」本局判你负；右侧聊天框可与对手 / 观战者实时交流（消息做了防注入处理）；每局结束按 ELO 段位结算，你的段位分显示在网络状态下方（胜加分、负减分，服务器持久保存）；右下角「音效」可随时开关落子 / 吃子 / 胜负等提示音。
  • 晒战绩 / 邀请好友：点「战绩海报」把本局胜负、段位分、总战绩生成一张带二维码的图片，保存后发微信朋友圈，好友扫码直接进你的房间；点「邀请好友」可看到自己的专属邀请码与链接，好友通过它进来会计入你的邀请人数，并解锁铜牌 / 银牌 / 金牌 / 钻石等推广成就。二维码由本机离线生成，不经过任何第三方服务。
  • 传统象棋规则（将/士/象/马/车/炮/兵）全部保留，先吃掉对方「将/帅」者获胜。

提示：同屏双人（hotseat）。轮到对方时请交接设备，点击「我准备好了」后再看棋盘，避免偷看对方暗棋。
